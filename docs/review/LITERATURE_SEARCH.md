# Bounded literature search and priority boundary

Source search and package review date: 2026-08-06 JST (UTC+09:00).

## Result

No source located in the bounded search states an unrestricted arbitrary-group
cell-count theorem beyond the Akman-Sissokho result through seven distinct
subgroups. In particular, no source located states the theorem through
seventeen cells. The search was bounded and does not establish priority.

The maintained Erdős Problems page currently identifies Problem 274 with the
general Herzog-Schönheim conjecture. Its historical abelian special case is
already known through the subnormal-subgroup result. This package compares
only unrestricted arbitrary-group cell-count results.

the primary papers above, the current arXiv record, the publisher's current

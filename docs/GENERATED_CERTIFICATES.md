# Generated Lean certificates

The two Python generators deterministically reproduce checked-in Lean source.
They are reproducibility tools, not assumptions of the theorem.

## Arithmetic certificates

`generate_arithmetic_kernel_certificates.py` reconstructs 18 modules,
`ArithmeticSearchCertificateD0.lean` through `D17.lean`. Together they cover
1,052 visited search states and prove that the complete seventeen-term
arithmetic output is the recorded list of five profiles.

Each nonterminal theorem unfolds one search step, kernel-checks its finite list
of admissible denominators, and rewrites recursive calls with deeper
certificate theorems. Terminal nodes are closed with `decide +kernel`.

## Fiber certificates

`generate_fiber_kernel_dfs_certificates.py` reconstructs exactly 251 modules:

| Kind | Count |
|---|---:|
| Profile data | 1 |
| Kernel leaves | 174 |
| Internal nodes | 71 |
| Profile endpoints | 5 |

The 174 leaves are distributed `30, 30, 30, 42, 42` across the five profiles.
The split threshold is 6,000 visited DFS states. Leaves close finite subtrees
with `decide +kernel`; each internal node unfolds exactly one transition and
rewrites every successful child with a checked theorem. The five root
endpoints say that the corresponding DFS returns `false`.

## Reproduction

The default modes are read-only and fail if the expected filename set or any
generated byte differs:

```bash
python3 -I search/e274/generate_arithmetic_kernel_certificates.py --check
python3 -I search/e274/generate_fiber_kernel_dfs_certificates.py
```

`--write` is reserved for deliberate regeneration followed by a complete Lean
build and axiom audit.
